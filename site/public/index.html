What is inside

Typed read client

Every public endpoint with canonical queries, retries that honor Retry-After, and decoded bigint state.

Live wallet stream

Server-sent events with revision-checked patches, backoff reconnects and automatic resync.

EIP-712 signing

Every intent, session keys that can trade but never withdraw, and the exact intent ids the relayer computes.

Settlement math

Bust prices, impact haircuts, win fees, the PAPER mint curve and staking rewards, exact to the wei.

Read-only MCP server

Seven tools at /mcp. Stateless Streamable HTTP, no login, no keys, no signing.

Agent-ready docs

Markdown twins, llms-full.txt, OpenAPI 3.1, a server card and an A2A agent card.

const client = new PapertradeClient();
const { instruments } = await client.tradingState();

streamWallet({
  wallet: '0x...',
  onState: (state) => console.log(state.positions.length, 'open positions'),
});

Verified against mainnet

  • Signatures. A real batched Close from HyperEVM recovers the trader's session key, and the SDK reproduces the relayer's intent ids.
  • Staking domain. The PaperStaking EIP-712 domain hashes to the contract's on-chain separator.
  • Liquidation prices. Exact on 205 of 205 sampled live positions.
  • Closes. Reproduces 15 of 15 leaderboard wins, a losing close's PAPER basis, and a mainnet liquidation.
  • Staking rewards. Matches PaperStaking.pendingReward to the wei.
