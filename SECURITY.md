# Security

Report vulnerabilities in this SDK privately through GitHub's "Report a vulnerability" on https://github.com/nirholas/papertrade-sdk/security. Do not open a public issue.

Vulnerabilities in the Papertrade protocol itself belong with the Papertrade team (https://papertrade.xyz), not here.

The SDK never sends private keys anywhere. Signing happens locally, and only signed intents are posted to the relayer.
